# truthlinked-axiom-compiler

The official compiler for the  language used to develop cells on TruthLinked.

It turns human-readable cell definitions (storage, functions, events, token/oracle primitives, access control) into Axiom bytecode + a manifest that the chain uses for safe parallel execution.

## Usage



See the main Cell SDK documentation for the full developer workflow, templates, and recommended patterns.

The compiler is the bridge between the ergonomic  authoring experience and the low-level Axiom VM.
